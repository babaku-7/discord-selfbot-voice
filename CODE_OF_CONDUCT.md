# Code of Conduct

## Our standard

Project participants must act respectfully, communicate clearly, and keep
contributions focused on improving this project.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Doxxing or publishing private information.
- Spam, scams, raids, token theft, or instructions intended to harm accounts
  or servers.
- Sharing Discord tokens, cookies, session data, or other secrets.
- Deliberate disruption of issues, pull requests, or project infrastructure.

## Reporting

Report unacceptable behavior privately to the maintainer through the
[maintainer's GitHub profile](https://github.com/babaku-7). Do not include
passwords, Discord tokens, cookies, or other sensitive data.

Public issues are suitable only for non-sensitive project discussion. The
maintainer may remove content or restrict participation when needed to keep
this project safe and usable.

## Scope

This code of conduct applies to repository issues, pull requests, discussions,
commits, and other project spaces controlled by this repository.
